# TaskKaro AI

An AI-powered, voice-enabled gig marketplace that connects customers who need everyday tasks completed with people seeking flexible earning opportunities.

## Planned Features
- Voice and text task requests
- English, Urdu, and Roman Urdu support
- AI-powered task understanding
- Intelligent worker matching
- Task tracking and status updates
- Worker earnings records
- Admin dashboard

## Planned Technology Stack
- Frontend: React.js / Next.js
- Backend: Python and FastAPI
- Database: SQLite or PostgreSQL
- AI: LLM API
- Version Control: Git and GitHub

## Project Status
Initial development and project setup.
